# Gift Shop — Telegram Mini App

Магазин подарков для Telegram в формате Mini App.

## Возможности

- Каталог товаров (сетка 2 в ряд)
- Карточка товара с фото, ценой в Stars и TON
- Кнопка «Купить» → открывает ЛС с @disndidbe
- Вкладка ИИ-помощника (отвечает только по магазину)
- Баннер «Файлы куки» (маленький, снизу)
- Админ-панель (только для @disndidbe)
- Русский / English

## Быстрый старт

```bash
npm install
npm run dev
```

Открой http://localhost:5173

## Как подключить к Telegram

1. Создай бота через @BotFather
2. Создай Mini App: `/newapp`
3. Укажи ссылку на задеплоенный сайт (Vercel / Netlify / свой сервер)
4. Готово

## Важно

- Единственный админ жёстко прописан: `disndidbe`
- При принятии куки данные пока пишутся в console.log — нужно добавить отправку на твой backend
- Демо-товары можно заменить в `src/App.tsx`

## Структура

```
src/
  App.tsx          — главный компонент
  pages/           — экраны (Catalog, Product, AI, Admin)
  components/      — CookieBanner, BottomNav
  i18n/            — переводы
  types/           — типы
```
